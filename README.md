# RG Jour J

App iPhone (web app hors connexion) compagnon de **RG**, l'application de régie générale.

- Journée du jour : heure, en cours, prochain, déroulé.
- Main courante : messages horodatés par service et sévérité, saisis hors connexion.
- Contacts : présents, lieux, production, compagnies, urgences.

**Aucune donnée dans ce dépôt.** Les journées arrivent du Mac par AirDrop (fichier préparé dans RG → Jour J → « Préparer l'iPhone ») et restent dans l'iPhone ; la main courante repart vers le Mac par AirDrop (menu ⋯ → Sync).

Installation : ouvrir https://frbou.github.io/rg-jourj/ dans Safari → Partager → Sur l'écran d'accueil.
